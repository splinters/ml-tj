# Synthetic data / Синтетические данные

Generated by `tools/make_synthetic_data.py`. Same files and columns as the pilot data, no client data: names, texts and coordinates are invented, numeric values are shuffled across rows and perturbed, contamination is re-generated from synthetic features. Results on these data do not reproduce the pilot results.

Создано скриптом `tools/make_synthetic_data.py`. Те же файлы и столбцы, что у данных пилота, без данных заказчика: названия, тексты и координаты придуманы, числа перемешаны между строками и изменены, загрязнение задано заново по синтетическим признакам. Результаты на этих данных не совпадают с результатами пилота.
