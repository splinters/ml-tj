# Блокноты ML TJ

Блокноты воспроизводят расчёты стенда **без базы данных и без интернета**. Единственный вход — выгрузка
`data/tajikistan_soil_ml_export.gpkg` (создаётся `python db/export_geopackage.py`; файл содержит данные заказчика
и не публикуется в открытом репозитории, см. `.gitignore`).

В открытой версии вместо данных пилота используется синтетический набор `data/synthetic/` (та же структура, придуманные значения;
создаётся `tools/make_synthetic_data.py`). Блокноты выбирают его сами, если данных пилота нет; другую папку можно задать
переменной `ML_TJ_DATA_ROOT`. Числа и выводы в тексте блокнотов относятся к данным пилота.

| Блокнот | Содержание |
|---|---|
| `demo_pop_screening.ipynb` | **демонстрационный**: СОЗ — слой данных, модель скрининга и её проверка, кривая отбора, перестановочный тест, оценка участка без анализов, индекс риска для детей и его устойчивость, план отбора |
| `demo_metals_xrf.ipynb` | **демонстрационный**: металлы — нормативы, приоритет складов, модель внутри склада и её проверка на складе вне обучения, кривая обучения, связь с СОЗ |
| `01_data_and_qc.ipynb` | состав данных, контуры, положение точек, диапазоны, пропуски ковариат |
| `02_model_pb_lowo.ipynb` | модель Pb, LOWO, разброс по случайному зерну, кривая обучения |
| `03_all_elements.ipynb` | та же проверка для 9 элементов (ответ на вопрос «почему только Pb») |
| `04_priority_and_risk_score.ipynb` | формула приоритета, индекс 0–100 и его уровни, расхождение индекса модели и приоритета |
| `00_quickstart.ipynb` | проверка локального стенда с БД (нужен PostgreSQL) |

`mltj.py` — общий код: загрузка выгрузки, признаки, LOWO. `demo_utils.py` — оформление демонстрационных блокнотов и подложка рельефа из локального растра `source_data/Terrain150_4326.tif`.

Демонстрационные блокноты читают, кроме выгрузки, файлы слоя СОЗ (`source_data/chemicals_tj/pop_layer/`) и код модели `db/pop_screening_model.py`. В HTML-версии код скрыт и раскрывается кнопкой «Показать код»; на стенде они открываются в разделе «Блокноты» (`/notebooks`).

## Запуск

```bash
python -m venv .venv-nb && . .venv-nb/bin/activate
pip install -r notebooks/requirements-notebooks.txt
cd notebooks && jupyter lab        # или: python build_html.py --out ../notebooks_html --execute
```

Путь к данным можно задать переменной `ML_TJ_GPKG`.

## Публикация на ВМ

См. `deploy/deploy_notebooks.sh` и `deploy/nginx_notebooks.conf`. Наружу публикуются **статические HTML-страницы**
под паролем: зрители ничего не запускают. Интерактивный JupyterLab (`deploy/jupyterlab.service`) работает только на
localhost и доступен через SSH-туннель.

## Воспроизводимость

Результаты LOWO зависят от случайного зерна леса (для Pb 0,157–0,178 при 12 зёрнах) и немного от версий библиотек.
После установки зафиксируйте версии: `pip freeze > notebooks/requirements-lock.txt` (делает `deploy_notebooks.sh`).
