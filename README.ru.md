# ML TJ: скрининг загрязнения почв и индекс риска для детей (Таджикистан)

*Предварительная открытая версия пилота. English version: [README.md](README.md).*

Пилот использует машинное обучение и открытые геоданные для инвентаризации бывших складов пестицидов и агрохимикатов в Таджикистане.

- **Скрининг СОЗ.** Модель упорядочивает участки по вероятности сильного загрязнения ДДТ и ГХЦГ. По ней участки без лабораторных анализов можно обследовать в разумной очерёдности.
- **Индекс риска для детей.** Опасность × дети рядом × уязвимость, по логике CCRI-DRM: риск = (H·E·V)^(1/3). Дети считаются по возрастным растрам WorldPop R2025A, бедность — по индексу относительного благосостояния Meta.
- **Тяжёлые металлы (XRF).** Модель упорядочивает точки внутри склада по ожидаемому содержанию свинца (Pb). Проверка идёт по складам, не участвовавшим в обучении.
- **Демо-стенд.** Веб-приложение на Flask и Leaflet на русском и английском. В нём карты, страницы моделей, методика, источники данных, блокноты, а также климатические слои и слои населения через GeoServer.

Все компоненты работают в изолированной сети: без CDN и без внешних запросов при работе, Leaflet входит в комплект. Подложку OpenStreetMap можно отключить.

## Структура

| Папка | Содержание |
|---|---|
| `webapp/` | демо-стенд: приложение Flask, шаблоны (RU + EN), встроенный Leaflet, документы методики |
| `db/` | конвейеры данных и модели: схема БД, импорт, ковариаты из открытых данных, слой СОЗ, модель скрининга, индекс риска для детей, модель металлов, справочник нормативов |
| `notebooks/` | блокноты Jupyter, воспроизводящие расчёты без БД (`demo_pop_screening`, `demo_metals_xrf`, `01`–`04`); результаты выполнения удалены |
| `geoserver/` | сборка слоёв населения из WorldPop и публикация GeoTIFF + SLD в GeoServer через REST |
| `deploy/` | примеры настроек nginx и systemd |
| `docs/` | установка, методика по металлам, словарь данных слоя СОЗ |
| `data/` | синтетический набор (`data/synthetic/`) и описание настоящих входных данных, см. [data/README.ru.md](data/README.ru.md) |
| `tools/` | скрипт, которым собирается эта открытая версия из рабочего проекта |

## Быстрый запуск: демо-стенд на синтетических данных

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
createdb soil_ml && psql -d soil_ml -c "CREATE EXTENSION postgis"     # PostgreSQL 14+ с PostGIS
export DATABASE_URL=postgresql://localhost:5432/soil_ml
python db/load_synthetic.py --reset          # схема, нормативы, синтетические склады, модель, зоны
python notebooks/build_html.py --out notebooks_html --execute   # по желанию: раздел «Блокноты» на стенде
DEMO_PASSWORD=придумайте-пароль python webapp/app.py           # http://127.0.0.1:5050 (пользователь demo)
```

На синтетике работают все разделы стенда: карта и таблицы металлов, приоритет складов, нормативы, модели, карта СОЗ с моделью скрининга и индексом риска для детей, методика, блокноты. Слои, которым нужны крупные открытые растры, пусты, пока растры не скачаны: рельеф, население, pH, реки (см. [data/README.ru.md](data/README.ru.md)). Разделу «Климат и население» нужен GeoServer.

Для настоящих данных полная установка (PostGIS, загрузка данных, ковариаты, расчёт модели) описана в [docs/SETUP.md](docs/SETUP.md). Настройки читаются из `.env` (см. `.env.example`).

Блокноты на синтетических данных:

```bash
pip install -r notebooks/requirements-notebooks.txt
cd notebooks && jupyter lab        # demo_pop_screening, demo_metals_xrf, 01–04
```

Конвейер СОЗ на настоящих данных:

```bash
python db/fetch_chemicals_tj.py --download-docs   # открытый реестр участков chemicals.tj (интернет нужен один раз)
python db/extract_pop_tables.py
python db/build_pop_layer.py
python db/pop_site_covariates.py
python db/pop_screening_model.py
python db/pop_child_risk_index.py                 # нужны WorldPop R2025A и RWI, см. data/README.ru.md
python db/pop_threshold_scenarios.py              # по желанию: сценарии 10 / 50 / 100 мг/кг
```

Слои населения для GeoServer:

```bash
python geoserver/build_population_layers.py
python geoserver/publish_rasters.py --dir geoserver_rasters/worldpop_2025 --workspace ML --mode upload --dry-run
```

## Данные

В репозитории **нет национальных данных и данных заказчика**; `data/synthetic/` — придуманные данные в том же формате. Это результаты обследований, измерения XRF, координаты из источников ограниченного доступа и персональные данные. Результаты расчётов тоже исключены. В [data/README.ru.md](data/README.ru.md) перечислены все входные данные: откуда они берутся, по какой лицензии и где их ждут скрипты. Открытые наборы (WorldPop, Meta RWI, SoilGrids, WorldClim, OpenStreetMap, JRC Global Surface Water) скачивают скрипты или пользователь.

## Статус и ограничения

- Это пилот. Модели обучены на 169 участках СОЗ с анализами и 10 обследованных складах. Они помогают выбрать очерёдность обследований, но не заменяют лабораторные анализы. Результаты проверки и ограничения приведены в документах методики (`webapp/templates/docs/`, PDF в `webapp/static/docs/`).
- В репозитории есть **синтетический набор данных** (`data/synthetic/`) с теми же файлами и столбцами, что у данных пилота. Блокноты и модель скрининга сразу работают на нём, без данных заказчика. Названия, тексты и координаты придуманы, загрязнение задано заново по синтетическим признакам, поэтому числа отличаются от результатов пилота, описанных в тексте блокнотов и в методике. Для работы с настоящими данными укажите в `ML_TJ_DATA_ROOT` папку с той же структурой.
- Накопление стока считалось в проприетарной ГИС. Расчёт переносится на открытые средства (WhiteboxTools или pysheds).
