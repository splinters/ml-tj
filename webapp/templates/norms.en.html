How to add a standard

  1. Document: a row in db/norm_sources_seed.csv (code, title, issuer, national or international, reference, link).
  2. Values: rows in db/norms_seed.csv (substance, mg/kg, form, land use, standard type, verification status).
  3. Use in the calculation: the source code in source_order of the profile in db/norm_profiles.csv (earlier in the list has priority).
  4. Apply:
python db/load_norms.py --profile <profile_id>

The script validates the files before writing (units, codes, source references, duplicates). No changes to the model or site code are needed. Tables: reference, measurements vs. standards.
