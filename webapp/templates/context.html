Как это используется

  • Нормативы. Если заказчик подтвердил целевое землепользование склада (документ или сообщение), сравнение замеров со справочником нормативов идёт по нему; для остальных складов действует тип землепользования активного профиля (Нормативы).
  • Модель концентраций не меняется. Контекст описывает, кто подвергается воздействию, а не сколько загрязнителя в почве; значения известны только по складам (10 площадок), и проверить их вклад кросс-валидацией LOWO нельзя.

Как заполнять и менять

  1. Заказчику отправляется Excel-шаблон addfiles/site_context_request.xlsx (лист «Контекст»).
  2. Проверка без записи: python db/load_site_context.py ФАЙЛ.xlsx --verification customer_doc --source "Письмо заказчика 2026-11-02" --dry-run
  3. Загрузка: та же команда без --dry-run. Ошибки (неизвестный склад, значение вне списка) выводятся до записи.
  4. Изменение значения: загрузить новое значение с новой датой или источником. Старое остаётся в истории, действующим становится более надёжное и более новое.
  5. Новый признак: строка в db/context_attributes.csv и повторный запуск, без правок схемы.
  6. Просмотр в консоли: python db/load_site_context.py --list.
