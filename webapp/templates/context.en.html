How it is used

  • Standards. If the client has confirmed the intended land use of a warehouse (document or statement), measurements are compared with the standards for that land use; for the other warehouses the land use of the active profile applies (Standards).
  • The concentration model does not change. Context describes who is exposed, not how much contaminant is in the soil; values are known only per warehouse (10 sites), so their contribution cannot be validated with LOWO cross-validation.

How to fill in and update

  1. The client receives the Excel template addfiles/site_context_request.xlsx ("Context" sheet).
  2. Dry-run check: python db/load_site_context.py FILE.xlsx --verification customer_doc --source "Client letter 2026-11-02" --dry-run
  3. Load: the same command without --dry-run. Errors (unknown warehouse, value outside the list) are reported before writing.
  4. Changing a value: load the new value with a new date or source. The old one stays in the history; the more reliable and more recent value becomes current.
  5. New attribute: a row in db/context_attributes.csv and a rerun, with no schema changes.
  6. Console view: python db/load_site_context.py --list.
