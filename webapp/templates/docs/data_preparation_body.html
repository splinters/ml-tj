Очистка и подготовка данных

Как из полевых замеров XRF и материалов портала chemicals.tj получены таблицы, на которых работают модели и карты стенда. Для каждого шага указано, что проверялось, что исправлено и каким скриптом это воспроизводится.

Общие правила для обеих тем: исходные файлы не изменяются; каждое значение в итоговых таблицах ссылается на документ или замер, из которого оно получено; спорные случаи не удаляются, а помечаются флагом и остаются в данных; все шаги выполняются скриптами и повторяются заново от исходных материалов.

1. Тяжёлые металлы (XRF)

1.1. Исходные данные

  • Полевые замеры портативным рентгенофлуоресцентным анализатором (XRF): 10 складов, 169 точек, 9 элементов (As, Co, Hg, Mo, Pb, Rb, Th, U, Zn).
  • Контуры складов (полигоны) и координаты точек замеров в формате GeoJSON.
  • Открытые данные для признаков модели: реки и каналы (OpenStreetMap), pH почвы (SoilGrids), рельеф, климат, население, землепользование, геология.

1.2. Загрузка и исправленные проблемы формата

Скрипт загрузки: db/import_data.py.

1.3. Контроль геометрии

  • Все 10 контуров проверены на корректность и самопересечения, все 45 пар контуров — на перекрытия и вложенность буферов (db/qc_geometry.py). Замечаний нет.
  • Площадь складов — от 0,05 до 1,07 га.
  • Внутри контура лежат 49 точек из 169; у точек снаружи медианное расстояние до контура — 49 м, 11 точек дальше 100 м, самая дальняя — 126 м. Точки вне контура не удаляются: расстояние до контура (со знаком «внутри / снаружи») и зона (внутри, до 50 м, до 100 м, дальше) используются как признаки модели.

1.4. Значения

  • Значения ниже предела обнаружения не отбрасываются: они заменяются половиной предела (LOD/2) и помечаются below_lod.
  • Для модели берётся логарифм концентрации и вычитается медиана логарифма по своему складу. Так модель учится положению очага внутри склада, а не различиям между складами; при 10 складах абсолютный прогноз по стране не получается.
  • У портативного XRF предел обнаружения мышьяка и ртути близок к нормативам, поэтому превышения по As и Hg рассматриваются как сигнал для лабораторной проверки. Для свинца и цинка XRF надёжен.

1.5. Признаки из открытых данных

Собраны и хранятся в базе все кандидаты: расстояние до воды, pH, уклон, высота, население, землепользование, геология, накопление стока, климат. Каждый проверен по одной схеме — обучение на 9 складах, проверка на десятом (LOWO). В модель вошли только признаки, которые не ухудшают качество в сочетании: расстояние до воды по точке (OpenStreetMap) и pH почвы по складу (SoilGrids). У одного склада нет значения pH — подставляется среднее по выборке. Подробности и результаты проверок — на странице «Методика: металлы».

Скрипты: db/fetch_point_covariates.py, db/fetch_landcover_population.py, db/diagnose_features.py, db/scan_all_substances.py.

1.6. Производные таблицы

  • Приоритет складов — db/rank_sites_priority.py: композитный индекс по Pb, As, Hg, Zn (превышение над медианой всей съёмки в логарифмах).
  • Зоны загрязнения внутри склада — db/build_risk_zones.py: по реальным точкам, без интерполяции.
  • Модель Pb — db/run_model_and_store.py.
  • Выгрузка для блокнотов без базы данных — db/export_geopackage.py → tajikistan_soil_ml_export.gpkg.

2. Участки СОЗ‑пестицидов (chemicals.tj)

2.1. Исходные данные

Структурированных таблиц у заказчика нет. Все сведения взяты из открытой части портала chemicals.tj:

  • карта: 192 участка типа «СОЗ» с координатами и статусом («загрязнённый» / «очищенный»);
  • анкета обследования по каждому участку — около 50 полей: площадь, запах, яма, доступ, вода, грунтовые воды, жители в кольцах 50/100/500 м и др.;
  • текстовое описание участка;
  • вложения: фотографии, лабораторные протоколы, журналы и реестры отбора проб, отчёты.

Скрипт выгрузки: db/fetch_chemicals_tj.py --download-docs.

2.2. Документы

  • Одни и те же документы прикреплены к разным участкам. Копии сведены по контрольной сумме файла и по совпадению извлечённого текста: из 373 вложений‑документов осталось 245 разных.
  • Документы классифицированы: лабораторный протокол, журнал или реестр отбора проб, отчёт, прочее. Определено, есть ли в PDF текстовый слой.

2.3. Извлечение анализов

Тип документаКак извлекаетсяПроверка
Текстовые PDF (протокол АФИ №8, отчёт ИЛИМ №42, таблица Института химии 2012 г., журналы)разбор таблиц по шаблонам; у журналов несколько разных шаблонов, в том числе блоки с несколькими участкамикаждое значение найдено дословно в тексте своего документа; 32 случая, где цифры перекрыты текстом соседней колонки, помечены

Скрипт: db/extract_pop_tables.py → extracted/measurements_long.csv.

2.4. Приведение к единому виду

  • Единица — мг/кг. Названия веществ приведены к единому словарю: ДДТ, ДДД, ДДЕ, изомеры ГХЦГ (α, β, γ, δ), альдрин, дильдрин, гептахлор и др.
  • «Не обнаружено» хранится как отдельный признак; в суммах групп считается нулём.
  • Колонки журналов без названия вещества сохраняются в отдельных полях и в показатель загрязнения не входят.
  • Показатель загрязнения участка — максимум по пробам из двух сумм: ДДТ+ДДД+ДДЕ и суммы изомеров ГХЦГ.
Исправленная ошибка сборки: если одно из веществ группы в пробе было «не обнаружено», сумма группы становилась пустой, и у части участков пропадало значение загрязнения. После исправления число участков с анализами выросло со 159 до 169; модель, индекс риска, план отбора и аудит пересчитаны.

2.5. Дубли между источниками

Одна и та же проба часто есть и в журнале отбора, и в лабораторном протоколе. Каждому значению присвоен ранг источника:

РангИсточникВ сводной выборке
1лабораторный протоколда
2журнал или реестр, если этой пробы нет в протоколахда
0журнал, дублирующий протоколнет, остаётся в данных с пометкой

При расхождении значений в сводную выборку идёт протокол. Реестры 2020 г. совпали с протоколом №8 по 47 из 48 участков. Итог: 586 проб и 2823 значения концентраций без дублей; всего извлечено 4572 значения.

2.6. Координаты проб

Лабораторные протоколы координат не содержат. Координаты перенесены из журналов и реестров того же участка, способ записан у каждой пробы:

  • по совпадению значения ДДТ в журнале и протоколе (протокол №126);
  • по порядку повторностей Т1/Т2/К3 в реестре (протокол №8);
  • по номеру пробы (отчёт ИЛИМ 2016 г.);
  • из самого журнала, если координаты указаны в нём.

Так получены координаты 462 проб; медианное расстояние от пробы до точки участка — около 30 м. Пробы без координат поставлены в точку участка с пометкой; участки, которых нет на карте, остаются без геометрии.

2.7. Связка кодов участков

В протоколе №126 12 участков записаны полевыми кодами tj77xx, которых нет на карте. 9 из них по названию села уверенно связаны с карточками карты (таблица manual/protocol126_map_links.csv), 3 остаются неоднозначными и вынесены в слой отдельными участками без координат. Код TJ‑7580 на карте использован дважды для разных карточек — участки различаются по координатам.

2.8. Сведения из текста карточек

Из текстовых описаний по шаблонам извлечено около 2200 фактов: расстояния до жилья, воды, дорог, посевов, школы и колодца; число жителей, детей, семей и домов; количество пестицидов, площадь; упоминания детей, скота, посевов, питьевой воды, жалоб на здоровье, ремедиации. Для каждого факта сохранён фрагмент текста‑основание, чтобы его можно было проверить.

2.9. Признаки из открытых данных

Для каждого участка по локальным растрам (без обращений в интернет) посчитаны: pH почвы (SoilGrids), высота и уклон (рельеф 150 м), население в радиусе ~500 м и 1 км (WorldPop 2020), накопление стока, среднегодовые температура и осадки (WorldClim 2.1). Скрипт: db/pop_site_covariates.py.

python db/import_data.py
python db/qc_geometry.py
python db/fetch_point_covariates.py
python db/rank_sites_priority.py
python db/build_risk_zones.py
python db/run_model_and_store.py "причина пересчёта"
python db/export_geopackage.py

python db/fetch_chemicals_tj.py --download-docs
python db/extract_pop_tables.py
