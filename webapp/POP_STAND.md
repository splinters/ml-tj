# Тема «СОЗ (пестициды)» на демо-стенде

Страницы:
- `/pop` — карта: участки СОЗ (риск для детей / загрязнение / скрининг), пробы, карточка участка,
  рейтинг и список кандидатов на обследование, форма «Оценить новый участок»;
- `/pop/model` — модель скрининга: кривая отбора, сравнение вариантов, кандидаты на обследование,
  ограничения, выгрузки.

Код: `pop.py` (маршруты), `pop_engine.py` (данные и модели), шаблоны `pop_map.html`, `pop_model.html`.
PostgreSQL для этой темы не нужен — всё читается из файлов.

## Что должно лежать на сервере

| Путь | Чем создаётся |
|---|---|
| `source_data/chemicals_tj/pop_layer/` (csv, `model/`, `child_risk/`) | `db/build_pop_layer.py` → `db/pop_site_covariates.py` → `db/pop_screening_model.py` (+ `final`) → `db/pop_child_risk_index.py` |
| `db/tjk_worldpop_2020.tif`, `db/tjk_ph.tif`, `source_data/Terrain150_4326.tif`, `source_data/flow/FlowAcc4326.tif`, `source_data/tj_clipped/past-trends/wc2.1_30s_bio/wc2.1_30s_bio_{1,12}.tif` | уже в проекте; нужны для оценки новой точки |
| `webapp/static/pop_hillshade.png` | создаётся автоматически при первом открытии карты (отмывка рельефа из DEM) |

## Запуск

Как и основной стенд: `DEMO_PASSWORD=... python webapp/app.py`.
`DEMO_BASEMAP=none` — без внешних тайлов (изолированная сеть): подложка «Рельеф (офлайн)» из локального DEM.
По умолчанию (`osm`) доступны OpenStreetMap и спутник Esri, «Рельеф (офлайн)» — в переключателе слоёв.

Модель скрининга обучается при первом обращении (доли секунды), сохранённый pickle не нужен.
После пересчёта слоя или модели перезапустите приложение — данные кэшируются в памяти процесса.

## Ограничения демо

- Ссылки на документы и фото ведут на chemicals.tj и не открываются в изолированной сети.
- Доля детей 0,40 принята единой по стране; школы — только по упоминаниям в карточках.
- Слой населения и подложка рельефа — растровые наложения, не тайлы; на крупных масштабах они размытые.
