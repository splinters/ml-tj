# Скрининг опасности участков СОЗ — модель v3 (пилот)

**v3 (текущая).** Исправлена ошибка сборки слоя: если одно из веществ группы ДДТ или ГХЦГ в пробе
«не обнаружено», сумма группы раньше становилась пустой, и у части участков пропадало значение
загрязнения. Теперь «не обнаружено» входит в сумму как 0. Обучающая выборка: 169 участков,
52 сильно загрязнены. Итоговая модель та же (набор G, логистическая регрессия, выбрана до
пересчёта): AUC 0,696, перестановочный тест p = 0,003. Отбор 20 участков с наибольшей оценкой —
13 сильно загрязнённых против 6,2 при случайном выборе; 30 участков — 19 против 9,2.
Доля сильно загрязнённых по классам: высокий 54 %, средний 18 %, низкий 19 %.
После исправления один только набор открытых ковариат (F) дал AUC 0,723 — в пределах разброса
от итоговой модели; модель не перевыбиралась, чтобы не подгонять выбор под результат.

## v1

Вопрос: можно ли по сведениям, доступным до лабораторного анализа, выделить участки
с сильным загрязнением хлорорганическими пестицидами.

**Цель.** Участок «сильно загрязнён», если хотя бы в одной пробе ДДТ+ДДД+ДДЕ или сумма
изомеров ГХЦГ ≥ 100 мг/кг (в 1000 раз выше норматива 0,1 мг/кг). Обучающая выборка:
151 обследованный участок карты, из них 52 сильно загрязнены (34 %).

**Признаки** (без сведений из анализов): анкета chemicals.tj; регион и координаты;
загрязнение соседних обследованных участков (5 ближайших, только из обучающей части);
открытые ковариаты — pH почвы, высота, уклон, население в радиусе ~500 м, накопление стока,
температура и осадки (`db/pop_site_covariates.py`, локальные растры).

**Проверка.** Пространственная кросс-валидация: участки делятся на 10 кластеров по координатам,
каждый кластер по очереди откладывается целиком; 10 повторов с разной разбивкой.
Значимость — перестановочный тест (метки перемешиваются, весь прогон повторяется).

## Результаты (`metrics.csv`)

| Набор признаков | Лучшая модель | AUC |
|---|---|---|
| A. Анкета | логистическая регрессия | 0,647 |
| B. Анкета + текст карточки | случайный лес | 0,599 |
| E. Регион/координаты + соседи | случайный лес | 0,648 |
| F. Открытые ковариаты | логистическая регрессия | 0,683 |
| **G. Анкета + регион/координаты + соседи + ковариаты** | **логистическая регрессия** | **0,701** |

Итоговая модель — G, логистическая регрессия: AUC 0,70, перестановочный тест p = 0,004.
Перебиралось 7 наборов признаков, поэтому лучшая оценка несколько оптимистична.
Текст карточки качество не улучшил: 30+ признаков на 151 участок дают переобучение.
Вероятности модели плохо откалиброваны, поэтому используется ранговая шкала `screen_score`
и три класса (низкий / средний / высокий) по третям проверочных оценок.

**Кривая отбора** (`selection_curve.csv`, `selection_curve.png`): при обследовании 20 участков
с наибольшей оценкой найдено 13 сильно загрязнённых против 6,9 при случайном выборе;
при 30 участках — 18 против 10,3. В классе «высокий» сильно загрязнено 55 % участков,
в классе «низкий» — 16 %.

## Дополнительная проверка (`check_linked_sites.csv`)

Восемь участков Пянджского и Кумсангирского районов есть на карте без анализов и в протоколе
АФИ №126 под полевыми кодами tj77xx (связаны по названию населённого пункта). Модель их не видела.
Все восемь загрязнены умеренно: максимум 3–44 мг/кг, порог 100 мг/кг не превышен ни на одном.
Модель отнесла 6 из 8 к классу «высокий». На этой группе модель завышает оценку: участки
загрязнены (в 30–440 раз выше норматива), но не до уровня основной цели. Это ограничение
указывается при использовании модели.

## Как использовать

Модель — инструмент очерёдности обследования, а не замена анализа: из 20 участков с наибольшей
оценкой примерно 13 окажутся сильно загрязнёнными, 7 — нет. Прогноз для участков без анализов —
`site_predictions.csv` (`score_type = прогноз`).
