# Слой СОЗ chemicals.tj — описание данных

Сводный слой по участкам типа «СОЗ» (устаревшие пестициды) с карты chemicals.tj/map-standalone,
дополненный лабораторными данными из прикреплённых документов и признаками из текстов карточек.
Сборка: `python db/build_pop_layer.py` (вход и порядок запуска — в шапке скрипта).
Система координат: EPSG:4326. Единицы концентраций: мг/кг (сухая почва, как в источнике).

## Состав `pop_layer.gpkg`

| Слой | Тип | Записей | Содержание |
|---|---|---|---|
| `pop_sites` | точки | 206 | 192 участка с карты + 14 участков, которые есть только в протоколе АФИ №126 (без координат, `on_map = false`) |
| `pop_samples` | точки | 589 | пробы сводной выборки, вещества в отдельных колонках |
| `pop_measurements` | таблица | 4572 | все извлечённые значения «проба × вещество», включая дубли (`source_rank = 0`) |
| `pop_text_facts` | таблица | 2200 | признак из текста + фрагмент текста-основание |
| `pop_files` | таблица | 3393 | все вложения участков СОЗ (фото, протоколы) со ссылками |
| `pop_sources` | таблица | 6 | источники лабораторных данных |

Те же таблицы лежат рядом в CSV (UTF-8 с BOM).

`source_rank`: 1 — лабораторный протокол; 2 — журнал без лабораторного дубля; 0 — дубль (журнал той же

## `pop_sites` — участок

**Идентификация и статус.** `tj_code` — код участка; `map_id` — id карточки на карте (код TJ-7580 на карте
встречается дважды); `on_map`; `pollution_status` (загрязнённый / очищенный); `region`; `site_date` — дата обследования;
`latitude`, `longitude`.

**Сводка анализов** (по сводной выборке):
`lab_n_samples`, `lab_n_samples_with_own_coords`, `lab_sources`, `lab_years`;
`ddt_max`, `ddd_max`, `dde_max`, `ddt_group_sum_max` (ДДТ+ДДД+ДДЕ в одной пробе);
`ddt_x_norm_max` — во сколько раз максимум ДДТ выше 0,1 мг/кг; `n_samples_ddt_gt_norm`;
`hch_sum_max` (сумма изомеров ГХЦГ в пробе), `g_hch_max`, `aldrin_max`, `dieldrin_max`, `heptachlor_max`,
`endosulfan_max`, `pesticides_total_max`; `substances_detected` — вещества со значением > 0.

**Признаки из текста карточки** (суффикс `_text` или префикс `mentions_`; основание каждого — в `pop_text_facts`):

| Поле | Что это |
|---|---|
| `site_kind_text` | тип объекта: склад, захоронение, полигон, аэродром/авиаплощадка |
| `building_state_text` | состояние: полностью разрушен / полуразрушен / используется / сохранился |
| `current_use_text` | текущее использование: жилая застройка, содержание скота, хранение, воинская часть |
| `pesticides_mentioned_text` | пестициды, названные в тексте |
| `dist_houses_m_text`, `dist_water_m_text`, `dist_road_m_text`, `dist_fields_m_text`, `dist_school_m_text`, `dist_well_m_text` | наименьшее расстояние (м), упомянутое в тексте, до жилья, воды (канал, арык, река), дороги, посевов, школы/детсада, колодца |
| `count_people_max_text`, `count_children_max_text`, `count_families_max_text`, `count_houses_max_text` | наибольшее упомянутое число людей, детей, семей, домов |
| `pesticide_quantity_kg_max_text`, `volume_m3_max_text`, `area_ha_max_text` | наибольшие упомянутые количество пестицидов (кг), объём (м³), площадь (га) |
| `years_mentioned_text` | годы, упомянутые в тексте |
| `mentions_*` | упоминание: дети, школа, мечеть/кладбище, доступ скота, посевы, запах, пятна, жалобы на здоровье, гибель животных, дома на участке или рядом, захоронение, мешки/тара, питьевая вода, орошение, ремедиация |
| `text_has_chatgpt_artifact` | в тексте карточки остался служебный фрагмент «ChatGPT сказал:» (6 участков) |

Это извлечение по шаблонам, а не ручная разметка: значения — подсказка для отбора и проверки, основание
каждого лежит в `pop_text_facts.snippet`.

**Поля анкеты с карты** (как на сайте): `square`, `depth`, `pit_dug`, `smell`, `land`, `source`, `status`,
`neformal`, `iss`, `issue_type`, население в кольцах `lived_/worked_/visited_` × `on_site/50m/100m/500m`,
`animals_food`, `agriculture_near`, `access`, `soil_cover`, `chemical_storage`, `water`, `surface_water`,
`surface_water_usage`, `river_distance`, `flood_zone`, `groundwaters`, `groundwaters_using`,
`groundwater_signs`, `groundwater_depth`, `another_water`, `well_distance`, `well_direction`,
`slope_position`, `health_effects` (везде «Нет» — неинформативно), `journalists_count`, `males`, `females`.

**Контроль качества:** `xrf_site`, `xrf_site_dist_m` — совпадение с XRF-складами проекта (< 300 м);
`nearest_pop_site`, `nearest_pop_site_m`; `qc_possible_duplicate` (другой участок ближе 50 м);
`qc_tj_code_repeated_on_map`; `qc_coords_low_precision` (меньше 4 знаков после запятой); `coord_decimals`.

**Файлы и тексты:** `n_photos`, `n_docs`, `doc_names`, `photo_urls` (до 10), `doc_urls`, `card_url`;
исходные тексты `problem_description`, `site_description`, `impact`, `notes`; `text_all` (только в GPKG).

## `pop_samples` — проба

`sample_id`; `tj_code`, `map_id`; `sample_label` — номер пробы в источнике; `source_id`, `lab`, `report_ref`,
`doc_file` (файл в `docs/`); `year`, `sample_date`, `depth_cm`, `sample_kind` (целевая/сборная);
`lat`, `lon`, `coord_source`, `dist_to_site_m`, `flags`.

Вещества (мг/кг): `DDT`, `DDD`, `DDE`, `a_HCH`, `b_HCH`, `g_HCH`, `d_HCH`, `HCH_ab` (α+β),
`HCH_unspecified` (изомер не указан), `heptachlor`, `heptachlor_epoxide`, `aldrin`, `dieldrin`, `endrin`,
`endrin_aldehyde`, `endosulfan_1`, `endosulfan_2`, `endosulfan_sulfate`, `methoxychlor`,
`pesticides_total` (сумма/хлорорганика), `unspecified_1/2` (колонка «Загрязнитель N» без названия).
`<вещество>_nd = true` — «не обнаружено» (значение пустое). Пустое значение без `_nd` — вещество не определялось.
Производные: `DDT_group_sum`, `HCH_sum`, `DDT_x_norm`, `DDT_gt_norm` (норматив ДДТ 0,1 мг/кг).

**Откуда координаты пробы (`coord_source`):**

|---|---|---|
| журнал проб (совпадение ДДТ) | 199 | протокол №126 без координат; координаты взяты из журнала того же участка с тем же значением ДДТ |
| реестр проб 2020 (порядок повторностей) | 142 | протокол АФИ №8; координаты Т1/Т2/К3 из реестра того же участка по порядку |
| документ | 92 | координаты указаны в самом журнале |
| журнал 2016 (номер пробы) | 29 | ИЛИМ 2016; координаты из журнала 2016 по номеру пробы (1 — целевая, 2 — смешанная) |
| точка участка | 81 | координат пробы нет; поставлена точка участка с карты |
| пусто | 46 | ни координат, ни участка на карте (участки только из протокола №126 и 2 пробы 2017 г. из Джами) |

## `flags` — пометки (пробы и значения)

| Флаг | Значение |
|---|---|
| `zero_reported` | в документе стоит 0; в протоколе №126 на этом месте «не обн.» — для расчётов считать ниже предела обнаружения |
| `order_2020` | реестр 2020 г.: «Загрязнитель 1…5» = ДДТ, ДДЕ, γ-, β-, α-ГХЦГ (сверено с протоколом АФИ №8) |
| `protocol_label_typo` | в протоколе №126 номер пробы напечатан с опечаткой (7486-2 в группе 7487, 7559-2 в группе 7561); участок — по группе |
| `site_by_label`, `site_by_settlement_name`, `site_by_district_name`, `site_by_row_order`, `site_by_nearest_<N>m` | как определён участок |
| `site_ambiguous`, `multi_site_block`, `site_unknown` | участок не определён |
| `journal_misattached:values_match_TJ-7545_protocol126` | журнал прикреплён на сайте к TJ-7447, но его значения совпадают с TJ-7545 по протоколу №126 |
| `dup_of_protocol126`, `dup_of_lab_protocol`, `dup_of_other_log` | дубль, в сводную выборку не входит |
| `value_from_overlap` | значение вытащено из ячейки, куда Excel вывел текст соседней колонки |
| `coords_far_from_site` | проба дальше 2 км от точки участка на карте (50 проб) |
| `coords_unaligned`, `coords_partial` | координаты из документа не удалось однозначно сопоставить строке |
