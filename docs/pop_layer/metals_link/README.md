# СОЗ и тяжёлые металлы на общих площадках

9 из 10 XRF-складов проекта совпадают с участками СОЗ chemicals.tj (ближе 150 м); Шахринав — нет.
Данные о ДДТ/ГХЦГ есть на 6 из 9 (Гиссар и Ёвон — только колонки без названия вещества, Пяндж — нет анализов).
Расчёт: `db/pop_metals_link.py`.

**Уровень площадки** (`site_level.csv`): приоритет по металлам и максимум пестицидов связаны слабо
(ранговая корреляция 0,37 по 6 площадкам, p = 0,47). Вахш и Дусти — верх рейтинга по металлам и
одни из самых загрязнённых пестицидами среди общих площадок; Джамийский район — высокий по металлам,
но пестицидов почти нет (0,17 мг/кг).

**Уровень точки** (`point_pairs.csv`): 12 проб СОЗ с координатами имеют точку XRF ближе 50 м.
Корреляция с Pb 0,29 (p = 0,36), с As, Hg, Zn — 0,14–0,21; по объёму данных значимость недостижима.
При этом внутри площадок есть совпадения очагов:
- Дж. Балхи: самая загрязнённая проба СОЗ (5,6 мг/кг) — рядом с точкой XRF с максимумом Pb на площадке (188 мг/кг, 1-я из 16);
- Дусти: две самые загрязнённые пробы СОЗ (26 и 37 мг/кг) — рядом с точкой XRF, 2-й из 19 по Pb (97 мг/кг);
- Кушониён: самая загрязнённая проба СОЗ (9,0 мг/кг) — рядом с точкой максимума Pb на площадке.

**Вывод для пилота.** Совпадение очагов на трёх площадках — основание проверить гипотезу, что на
складах пестициды и металлы (в т.ч. из ртуть- и мышьяксодержащих препаратов, тары, топлива техники)
концентрируются в одних местах. Для проверки нужен совместный отбор: XRF и лабораторный анализ
пестицидов в одних точках. Это можно включить в план следующей кампании.
